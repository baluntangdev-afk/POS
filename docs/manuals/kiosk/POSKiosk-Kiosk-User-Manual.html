1. Getting to know the system

The POS Kiosk is a touch-screen point-of-sale for a single store lane. It runs on a Windows machine and is made of three parts that work together.

PartWhat it isYou interact with it?
Kiosk appThe full-screen touch application on the counter (and, optionally, a second customer-facing screen).Yes — this whole manual.
Backend serviceA program running in the background on the same machine that stores products, sales, users and reports.No — it has no screen.
DatabaseWhere all the data physically lives (PostgreSQL).No.

User roles

Every staff member has one role. The role decides which tiles appear on the main menu.

RoleCan do
Cashier UserTake orders, accept payment, apply discounts, reprint / refund / void from Transactions, run X-Reading and cashier reports.
SupervisorEverything a cashier can do, plus authorise refunds and voids, manage products and users, close Z-Readings, run Backup & Transfer.
AdminEverything. Full access to every tile, all settings and the terminal registration.
Note  A supervisor or admin PIN can be entered on the spot to approve a refund, a void or a report close — even when a cashier is the one signed in.

What you need before first use

  • The machine is powered on and connected to the same network / internet as usual.
  • The POS Kiosk software has been installed by IT (services POSBackendService and POSPostgres are running).
  • At least one employee account exists. On a brand-new install only the seeded admin exists — sign in as that admin first and add your real staff (Section 13).
  • This terminal has been registered once with the store's legal name, address and TIN (Section 14).

2. Starting the kiosk and signing in

2.1 Launch and start-up check

  1. Double-click the POS Kiosk shortcut on the desktop (in production it opens full-screen automatically).
  2. The start-up screen appears and checks that the backend is responding. This normally takes a few seconds.
  3. If it says “Services are taking a moment to start…” for more than ~20 seconds, wait — Windows may still be starting the background services. If it never clears, see Section 17.
  4. When the check passes you are taken to the Welcome / Touch To Start screen.

2.2 Sign in

  1. On the Welcome screen, tap Touch To Start.
  2. The “Who's working?” screen shows a tile for every active employee. Tap your name.
  3. Enter your 6-digit PIN on the on-screen keypad. It submits automatically once the 6th digit is entered.
  4. If the PIN is wrong, a red message appears and the entry clears — try again.
  5. On success you land on the main menu, showing only the tiles your role allows.
Note  There is no username/password screen on the kiosk. Login is always name + 6-digit PIN. Email / User-ID login exists only in the backend API.

2.3 First login — set your PIN

New accounts (and accounts whose PIN was reset) are forced to choose a personal PIN before they can continue.

  1. After entering the temporary PIN you will see “You need to change your PIN to continue”. Tap Change PIN.
  2. On Create your PIN, key in a new 6-digit PIN.
  3. On Confirm your PIN, key in the same 6 digits again. If they don't match you are asked to start over.
  4. You'll see “User PIN has been updated successfully. Please login again.” — sign in once more with your new PIN.
Important  The seeded admin account (name Cody Admin) ships with PIN 123456. Change it immediately on first login.

4. Module: New Order — building a sale

Opened from New Order. Left side is the product grid, right side is the running order.

4.1 Find and add a product

  1. Use the category chips along the top to switch sections. Swipe or tap the arrows to see more chips.
  2. Tap a product card. The item-options dialog opens.
  3. If the product has variants (e.g. Small / Medium / Large), tap the one you want — the price updates.
  4. If the product has modifier groups (e.g. sugar level, add-ons), tap options to select them. Groups marked “Select 1” behave like radio buttons; “Select up to N” behave like check-boxes. The Confirm button stays disabled until every required group is satisfied.
  5. Set the quantity with the − / + buttons.
  6. Tap Confirm. The line is added to the order panel on the right.

4.2 Work with the order panel

  • Tap a line to expand it. From there you can change quantity, set the line's Dine In / Take Out type, add a note (e.g. “no onions”), or delete the line with the red bin icon.
  • On the wide kiosk layout the panel is always visible on the right; on a narrow screen tap the receipt / cart icon in the header to slide it in.
  • The footer shows the live breakdown: VATable Sales, VAT-Exempt Sales (if any), VAT, Discount (if any) and Total.
  • A line that already has a discount is locked for quantity edits — remove the discount first (Section 5) to change it.

4.3 Move to payment

  1. Optionally tap Apply Discount (see Section 5).
  2. Tap Proceed to Checkout / Proceed to Payment. The button is greyed out until the order has at least one line.
  3. On tablet/phone layouts an Order Summary step is shown first; on the kiosk layout you go straight to the payment screen.

5. Module: Apply Discount

Reached from the Apply Discount button on the order panel, the cart, or the checkout. Two discount types are supported.

TypeUse forExtra info required
Senior / PWDGovernment-mandated senior citizen and person-with-disability discount. Removes VAT on the chosen items and applies the statutory percentage.ID Number and Name of ID Holder.
PromoA promotional / manual discount.Promo Code.

5.1 Apply a discount

  1. Tap Apply Discount. The discount screen (or dialog) opens with your order items on one side and the discount controls on the other.
  2. Tick the items the discount should cover. Use Select All / Deselect All for the whole order. For a line with quantity > 1 you can choose how many units are covered with the stepper (“3 of 5”).
  3. Choose the discount type (Senior/PWD or Promo).
  4. Fill in the required field(s): ID Number + Name of ID Holder for Senior/PWD, or Promo Code for Promo.
  5. Review the summary (Selected Total, VAT Exempt, Discount).
  6. Tap Apply Discount. Discounted lines show a “LESS: …” / Discounted badge back on the order.

5.2 Remove a discount

  • On the order panel or cart, tap the “LESS: …” / Discounted badge (or its ×) on the line to clear that line's discount.
  • In the discount dialog, items already discounted appear grouped by beneficiary with a Remove button that clears the whole beneficiary group at once.
Note  Items that already carry a discount are shown locked in the picker so the same discount can't be stacked twice.

6. Module: Checkout & Payment

6.1 Take payment

  1. The payment screen lists the Order Total and the VAT breakdown on one side and the payment methods configured for this terminal on the other.
  2. Tap the method the customer is using (e.g. Cash, Credit / Debit Card, or an e-wallet).
  3. For Cash: enter the amount tendered on the keypad. The system shows the change due automatically.
  4. For Card: enter the reference number and the last 4 digits of the card.
  5. For an e-wallet / QR method: enter the reference number from the customer's payment confirmation.
  6. Tap Confirm Payment. While it processes the button shows Processing…
  7. On success the receipt screen appears.
Note  Tapping Back during payment asks “Cancel Payment?” — choose Stay to keep going or Cancel Payment to return to the order without charging.

6.2 Receipt

  • The receipt screen shows the store header (legal name, address, TIN, terminal serial number), the line items, totals and the payment.
  • Use the on-screen action to print the receipt to the connected ESC/POS printer.
  • Finishing the receipt returns you to a fresh New Order.

7. Module: Orders (channel / online orders)

Opened from Orders. This is a live board of orders that arrive from outside the kiosk (online ordering, delivery apps, etc.). The main-menu tile carries a badge with the pending count.

7.1 Read the board

  • Orders are shown as cards in a kanban board with columns Pending → Preparing → Fulfilled, plus Cancelled.
  • The filter row at the top narrows by fulfilment type: All, On-Site, Pickup, Delivery, Other.
  • Each column footer shows a running Total. An empty column reads “No … orders yet”.
  • New orders appear automatically as they come in — no need to refresh.

7.2 Act on an order

  1. Tap a card to open order items and see the full contents and total.
  2. Advance an order to the next stage using its card control as each step is done.
  3. To cancel one order, use the card's cancel action and confirm “Cancel this order?” → Cancel order.
  4. To clear the whole board, use Delete all orders in the header and confirm “Delete all orders?” → Delete all.
Important  Delete all orders is destructive and cannot be undone. Use it only for a genuine reset (e.g. end of a test period).

8. Module: Transactions

Opened from Transactions. A searchable, sortable, paged table of completed sales, and the gateway to all cashier reports.

8.1 Find a sale

  • Columns: Invoice #, Cashier, Date, Time, Total, Actions.
  • Tap the Date header to sort; use Previous / Next to page through results.

8.2 Reprint a receipt

  1. Find the sale in the table.
  2. Tap Reprint in its Actions cell. The original receipt is sent to the printer again.

8.3 Refund a sale

  1. Tap Refund on the sale's row. The Process Refund screen opens.
  2. Select the item(s) and quantities to refund (full or partial).
  3. Enter a Reason for Refund.
  4. When prompted with “Authorization Required”, a Supervisor or Admin enters their PIN.
  5. Confirm. You'll see “Refund Processed” and the refund is recorded against the sale.

8.4 Void a sale

  1. Tap Void on the sale's row.
  2. Enter a Reason for Void.
  3. A Supervisor or Admin authorises with their PIN.
  4. Confirm. You'll see “Transaction Voided” and the sale's status changes to Voided.
Important  A voided sale cannot be un-voided. Check the invoice and amount before authorising.

9. Module: X-Reading & Cashier Daily Report

Both are opened from buttons in the Transactions header. They summarise your own sales on this terminal for today.

9.1 X-Reading (mid-shift read)

  1. In Transactions, tap X-Reading. The current figures load and the X-Reading screen opens.
  2. Review: Sales Summary (Total Sales, Average / Highest / Lowest Sale), Transaction Summary (Completed, Refunded), Discount Summary, Tax Summary, Cash Collected, Total Qty Sold.
  3. Tap Print X-Reading to print a copy. This does not close the shift — you can run an X-Reading as often as you like.

9.2 Cashier Daily Report

  1. In Transactions, tap Cashier Daily Report.
  2. Review the BIR-style breakdown: Gross Sales, Vatable / Zero-Rated Sales, Net of Tax, No. Transactions, Total Quantity, Cash Sales, Sales by Product, and the Cash Ledger.
  3. Tap Print Cashier Report.
  4. To close the day's cashier report, use the close action and authorise if prompted. Closing files it into report history.
Note  “Close” on a report finalises that day's numbers and moves the report into history (Section 11). Print first if you need a paper copy.

10. Module: Z-Reading (end of day)

Opened from the Z-Reading button in the Transactions header. The Z-Reading is the store-wide end-of-day close and is authorised.

10.1 Run and close a Z-Reading

  1. In Transactions, tap Z-Reading. Current store-wide figures load.
  2. Review the full report: Grand Total (Beginning / Ending Balance), Sales Summary, Qty × Product, Transaction Summary (Completed / Refunded), Discount Summary, Tax Summary, Cash Collected, Total Qty Sold and Sales by Cashier.
  3. Tap Print Z-Reading for the paper copy.
  4. To close: use the close action. The “Z-Reading Close Authorization” dialog appears — a Supervisor or Admin enters their PIN and taps Authorize Close.
  5. After closing, the Z counter advances and the report is stored in history with the names of who closed and who authorised it.
Important  Close the Z-Reading once per business day, after the last sale. It cannot be re-opened.

Reprint

A closed Z-Reading can be reprinted from its screen with Reprint Z-Reading, or later from report history.

11. Module: Report history

Opened with the Reports button in the Transactions header. Lets you look up and reprint reports that were closed earlier.

  1. Tap Reports. The history screen opens with three tabs: X-Reading, Cashier Daily Report, Z-Reading.
  2. Pick a tab. Closed reports are listed newest first, paged (“Page X of Y”). Empty tabs read “No closed … yet”.
  3. Tap a row to open that historical report exactly as it was closed.
  4. Use the Reprint action on the opened report to print another copy.

12. Module: Inventory Management (products & categories)

Opened from Inventory. Despite the name this is your product catalogue editor. It has two tabs: Products and Categories.

12.1 Categories tab

  1. Open Inventory → Categories.
  2. Tap Add Category. Enter a Name, an optional Description, and set the Active toggle.
  3. Tap Save.
  4. For an existing category use the row menu: Edit, or Disable / Enable (an inactive category and its products are hidden from the New Order screen).

12.2 Products tab — add a product

  1. Open Inventory → Products and tap Add Product.
  2. Enter the Name.
  3. Choose a Category (required).
  4. Optionally add an Image (“Image (optional)” / “Replace Image”).
  5. Add at least one Variant: tap Add Variant, give it a name (e.g. “Regular”, “Venti”) and a price of at least 0.01. Mark one variant as the default (star). Disable a variant to hide it without deleting.
  6. Tap Save. The product appears immediately on the New Order screen (categories/products refresh each time that screen opens).

12.3 Edit / disable a product

  • Search with the Search products… box or filter by category chip.
  • Open a product to Edit its details, image and variants; tap Update to save.
  • A product with no enabled variant shows a Disabled badge and won't sell.

12.4 Import products from CSV

  1. On the Products tab tap Import CSV.
  2. Tap Download template to get a correctly-formatted file. Columns: Category, Product Name, Variant Name, Price, and optionally Product Image URL.
  3. Choose the import mode: Add & Update (Upsert) — nothing already in your menu is removed; or Replace Entire Menu — wipes the current menu first.
  4. Tap Choose CSV file and select your file.
  5. Tap Import. When it finishes you'll see an Import Complete summary.
Important  Replace Entire Menu asks “Replace Entire Menu?” → Yes, Replace and cannot be undone. Prefer Upsert unless you are deliberately rebuilding the catalogue.

13. Module: Modifier Groups

Modifier groups are the add-on / choice lists attached to products (sugar level, extra shot, toppings). Managed from the Modifier Groups screen within Inventory.

13.1 Create a modifier group

  1. Open Modifier Groups and tap Create New Group.
  2. Enter the Group Name.
  3. Set the minimum and maximum selections. Min 1 / Max 1 makes a required single-choice (radio) list; Min 0 / Max 3 makes an optional pick-up-to-three list.
  4. Add each option with Add Modifier: give it a name and an optional extra price.
  5. Save the group.

13.2 Assign, edit and delete

  • The list shows each group's Modifiers count and Used By (how many products use it).
  • Edit Group to rename it, change min/max, or add/remove options.
  • Attach a group to a product from the product editor (Section 12).
  • Delete Group removes it — do this only if no products still rely on it.

14. Module: User (employee accounts)

Opened from User. Add and maintain the staff who can sign in to this kiosk.

14.1 The list

  • Stat cards across the top: Total Users, Admins, Supervisors, Users.
  • Search by name, email, or ID; filter by role with the All Roles selector.

14.2 Add an employee

  1. Tap Add User.
  2. Personal Information: Employee ID (required), First Name (required), Middle Name, Last Name (required).
  3. Contact Details: Phone Number (validated).
  4. Account Settings: set Status (Active / Cancelled) and User Type (User, Supervisor, Admin).
  5. Tap Create User. You'll see “User has been created successfully.”
Note  New employees receive the default PIN and are forced to set their own on first sign-in (Section 2.3). The default kiosk PIN is 123456 unless your installer changed it.

14.3 Edit, reset PIN, delete

  • Edit a row to update details or change the role/status, then Update User.
  • Reset Pin (in the edit dialog) puts the account back to the default PIN and forces a new one at next login — use this when someone forgets their PIN.
  • Delete removes the account (confirm in the Delete User dialog). Their past sales stay in history but they can no longer sign in.

15. Module: Settings — terminal & payment methods

Opened from Settings. Holds the identity of this lane and the payment methods it offers. On a brand-new machine you register the terminal here first.

15.1 Register this terminal (first time only)

  1. If the menu shows “No POS Terminal Assigned”, tap Register POS (or open Settings).
  2. On Register POS Terminal enter the store's Legal Name, Address and TIN Number.
  3. Add the Payment Methods you will accept (see 15.3).
  4. Tap Register Terminal.

15.2 View / edit terminal details

  1. Open Settings. The dialog shows “View and edit your terminal information.”
  2. Edit Legal Name, Address, TIN Number as needed — these print on every receipt and report.
  3. The Kiosk ID is shown here (with a copy button). It is the number that appears in every invoice number, e.g. SO-001-2026-0001.
  4. Tap Save Changes.

15.3 Payment methods

  1. In the terminal dialog, under Payment Methods, tap Add Payment Method.
  2. Enter the Payment Method Name (e.g. Cash, Credit Card, GCash) and an optional Payment Number (account / merchant number for e-wallets).
  3. Save. The method now appears on the payment screen.
  4. Use Edit / remove on a method to change or retire it.
Note  Only methods named exactly Cash and Credit Card get the special cash-tendered and card-reference input flows; any other name is treated as a reference-number (e-wallet) method.

16. Module: Backup & Transfer

Opened from Backup & Transfer. Moves this device's entire dataset — staff and PINs, products, every sale, payment, refund and report — to a replacement machine. Admin / Supervisor only.

16.1 Export a backup (on the OLD machine)

  1. Open Backup & Transfer → Export Backup → Start Export.
  2. Enter and confirm a passphrase (at least 12 characters). Write it down — the file is useless without it and it cannot be recovered.
  3. Authorise with a Supervisor PIN when prompted (Authorize Export).
  4. Choose where to save pos-kiosk-backup-<date>.posbackup (e.g. a USB drive).
  5. Wait for “Backup Saved”. Treat the file like a list of everyone's PINs — it contains them (encrypted).
Note  Exporting does not change the old machine. Keep trading on it until the new one is ready.

16.2 Import & restore (on the NEW machine)

  1. Install the POS software on the new machine and let it reach the login screen once.
  2. Sign in as Admin/Supervisor (use the seeded admin if no staff exist yet).
  3. Open Backup & Transfer → Import & Restore → Start Restore.
  4. Choose backup file (.posbackup), enter the passphrase, and type REPLACE in the confirmation box.
  5. Authorise with a Supervisor PIN (Authorize Restore), then tap Replace All Data.
  6. Wait for “Restore Complete” — do not close the app while it runs. You are signed out automatically; sign back in with the credentials from the old machine.

16.3 &ldquo;Incompatible Backup&rdquo; / Partial restore

If the two machines are on different app versions you'll see “Incompatible Backup”. The best fix is to update both to the same version and export again. If that isn't possible, tick Partial restore — only the data both versions have in common is imported, and a summary lists what was skipped.

Important  A restore wipes whatever is on the new machine and replaces it with the backup, including receipt / official-receipt sequence numbers. Only run it on a fresh replacement device.

17. Customer display (second screen)

If a second monitor is connected, the kiosk automatically opens a customer-facing display on it. It needs no operation — it mirrors what the cashier is doing.

  • Idle: a rotating showcase of menu items.
  • During an order: the live list of items and the running total the customer is being charged.
  • After payment: a thank-you screen, then back to idle.
Note  The customer display picks the non-primary monitor automatically. If it appears on the wrong screen, swap the monitor cables or set the correct primary display in Windows, then restart the app.

18. Signing out & switching users

  1. From the main menu tap Sign Out (top corner, logout icon).
  2. You return to the “Who's working?” screen.
  3. The next person taps their name and enters their PIN.
Note  Always sign out at the end of your shift so sales and X/Z readings are attributed to the right cashier. Run your Cashier Daily Report / X-Reading before handing over.
